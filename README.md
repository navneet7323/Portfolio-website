# Portfolio Website

A modern, responsive personal portfolio website built to showcase my skills, projects, and frontend development experience.

## 🚀 Features

- Responsive design for desktop, tablet, and mobile
- Modern UI/UX
- About section
- Skills section
- Services section
- Projects showcase
- Contact section
- Resume download option
- Smooth animations and interactions

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Responsive Web Design
